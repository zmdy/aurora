Architecture

How Aurora Works

01

PHP Registers Controls

Each module hooks into Elementor's Advanced tab via elementor/element/*/section_effects/after_section_end.

02

PHP Injects data-* Attrs

Settings are serialised as data-aurora-* attributes on the element wrapper before rendering — zero runtime PHP.

03

JS Detects & Plays

The core runtime reads those attributes, splits text, and runs the selected effect — triggered by IntersectionObserver or on load.

04

Per-Widget Chunking

On the real frontend only the ONE effect a widget uses is enqueued. The 50KB full bundle stays out of every page that doesn't need it.

<!-- PHP renders this on the element wrapper --> <div data-aurora-enable="1" data-aurora-library="gsap" data-aurora-animation="gs-1" data-aurora-split-by="chars" data-aurora-duration="800" data-aurora-stagger="35" data-aurora-trigger="scroll" data-aurora-threshold="0.3" data-aurora-replay="1" > Your Heading Text Here </div>

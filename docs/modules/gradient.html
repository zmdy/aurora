JavaScript API

var fx = Aurora.gradient(document.querySelector('.hero'), {
  type: 'radial',
  stops: '#7c6cff;#ff7a2f;#2af598',
  followMouse: true
});
fx.destroy();          // removes every style it added

Options

Set them as data-aurora-gradient-<option> attributes, as one JSON attribute (data-aurora-gradient-options) or as an object in JavaScript.

OptionAttributeTypeDefaultDescription
typedata-aurora-gradientenumlinear"mesh" renders an animated WebGL gradient and only applies to backgrounds.
linear radial conic mesh
targetdata-aurora-gradient-targetenumbackgroundWhere the gradient is drawn: the element background, the text fill, an icon (font or SVG), or both the icon and the text.
background text icon icon-text
selectordata-aurora-gradient-selectorselectorFor text and icon: the elements to paint, relative to this element. Empty paints the element itself (text) or its icons (icon). With "icon-text" it is the icon selector.
textSelectordata-aurora-gradient-text-selectorselectorOnly used by "icon-text": the text elements to paint, relative to this element. The Target selector then paints the icons.
stopsdata-aurora-gradient-stopsstring#7c6cff;#ff7a2f;#2af598Colors separated by ";", each with an optional position: "#ff0080;#7928ca 60;#2af598". A JSON array of {color, offset} is also accepted.
angledata-aurora-gradient-anglenumber (deg)135Angle
animationdata-aurora-gradient-animationenumnone"flow" moves color blobs (backgrounds) or pans the gradient (text, icons); "hue" rotates the hue.
none flow hue
speeddata-aurora-gradient-speednumber (s)8Cycle duration
followMousedata-aurora-gradient-follow-mousebooleanfalseA radial gradient that follows the pointer over the element.
spotlightRadiusdata-aurora-gradient-spotlight-radiusnumber (px)600Spotlight radius
textModedata-aurora-gradient-text-modeenumphraseFor text split by the Text module: one gradient across the whole phrase, or a full gradient on every unit.
phrase letter

Copy and paste

This is a complete HTML file. It needs no build step and no framework. The two scripts weigh 4.4 KB + 3.8 KB gzipped.

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Aurora Counter (standalone)</title>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/zmdy/aurora@v1.0.0/dist/vendor/animated-headline.css">
<style>
body { margin: 0; min-height: 100vh; display: grid; place-items: center; padding: 24px; background: #0b0b12; color: #ecebf5; font: 16px/1.5 system-ui, sans-serif; }
h2 { font-size: clamp(2rem, 6vw, 3.4rem); margin: 0; text-align: center; }
</style>
</head>
<body>

<h2 data-aurora-counter="progress"
    data-aurora-counter-to="1250" data-aurora-counter-suffix="+"></h2>

<script type="module" src="https://cdn.jsdelivr.net/gh/zmdy/aurora@v1.0.0/dist/vendor/animated-headline.js"></script>

        crossorigin="anonymous"></script>
<script src="https://cdn.jsdelivr.net/gh/zmdy/aurora@v1.0.0/dist/aurora.counter.min.js"

</body>
</html>

JavaScript API

var fx = Aurora.counter(document.querySelector('h2'), { kind: 'countdown', target: '2026-12-31T23:59' });
fx.update({ kind: 'clock', format: '24h' });
fx.destroy();

Options

Set them as data-aurora-counter-<option> attributes, as one JSON attribute (data-aurora-counter-options) or as an object in JavaScript.

Aurora Animated Headline

A few words. A lasting impression.

Frame a phrase with an animated shape or rotate through your ideas. The same Text module, in HTML, Webflow and Elementor.

Aurora.text() · headline

Create extraordinary experiences.

HighlightedAurora original
Use this headline on your site

In Elementor, add Aurora Animated Headline. Set Before Text, Highlighted Text and After Text, then choose Highlighted or Rotating. Shape choices include Underline, Zigzag, Strike, Orbit, Wave, Spark, Frame and Text Highlighter; rotation includes whole-phrase Prism Rise, Comet Slide, Split Flap, Soft Focus, Curtain Wipe and Drop Bounce, plus letter-by-letter Airport Flip, Scramble, Sparkles, Reveal Wall, Letter Swap, Echo Clone, Typewriter and Wave Pop. Adjust letter stagger and accent colors to match your design.

JavaScript API

var fx = Aurora.text(document.querySelector('h2'), { effect: 'blur-reveal', split: 'words' });
fx.replay();               // play again
fx.update({ duration: 1200 }); // change options
fx.destroy();              // restore the original markup

Text

Split any text into characters, words or lines and animate it on scroll or on load. Built on Anime.js v4.

JavaScript API

var fx = Aurora.text(document.querySelector('h2'), { effect: 'blur-reveal', split: 'words' });
fx.replay();               // play again
fx.update({ duration: 1200 }); // change options
fx.destroy();              // restore the original markup

Options

Set them as data-aurora-text-<option> attributes, as one JSON attribute (data-aurora-text-options) or as an object in JavaScript.

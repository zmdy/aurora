Copy and paste

This is a complete HTML file. It needs no build step and no framework. The two scripts weigh 4.4 KB + 3.9 KB gzipped.

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Aurora Animate Children (standalone)</title>
<style>
body { margin: 0; min-height: 100vh; display: grid; place-items: center; padding: 24px; background: #0b0b12; color: #ecebf5; font: 16px/1.5 system-ui, sans-serif; }
h2 { font-size: clamp(2rem, 6vw, 3.4rem); margin: 0; text-align: center; }
.tiles { display: grid; grid-template-columns: repeat(3, 1fr); gap: 12px; width: 100%; max-width: 520px; }
.tile { background: #1b1b29; border: 1px solid #2a2a3d; border-radius: 12px; aspect-ratio: 1.3; display: grid; place-items: center; font-weight: 700; }
</style>
</head>
<body>

<div class="tiles" data-aurora-children="slide" data-aurora-children-direction="up">
  <div class="tile">1</div>
  <div class="tile">2</div>
  <div class="tile">3</div>
  <div class="tile">4</div>
  <div class="tile">5</div>
  <div class="tile">6</div>
</div>

JavaScript API

var fx = Aurora.children(document.querySelector('.grid'), { animation: 'zoom', stagger: 90 });
fx.replay();
fx.destroy();

Options

Set them as data-aurora-children-<option> attributes, as one JSON attribute (data-aurora-children-options) or as an object in JavaScript.

animationdata-aurora-childrenenumfadeEntrance or emphasis animation. "none" keeps only the hover effect.
none fade slide zoom bounce rotate flip blur focus pulse shake tada rubber-band wobble
directiondata-aurora-children-directionenumup"up" starts below the final position and moves up.
up down left right none

none horizontal vertical

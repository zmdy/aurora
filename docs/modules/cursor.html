Cursor Follow

A custom cursor scoped to an element: a dot that follows instantly and a ring that trails behind. The native cursor stays visible unless you turn it off.

Move the mouse here and hover this link

Open the standalone example

Live attributes

Change the controls and copy the attributes onto any element.

JavaScript API

var fx = Aurora.cursor(document.querySelector('.area'), { dotColor: '#ff7a2f', hideNative: false });
fx.destroy();

Options

Set them as data-aurora-cursor-<option> attributes, as one JSON attribute (data-aurora-cursor-options) or as an object in JavaScript.

OptionAttributeTypeDefaultDescription
dotColordata-aurora-cursor-dot-colorcolor#ff7a2fDot color
ringColordata-aurora-cursor-ring-colorcolor#7c6cffRing color
dotSizedata-aurora-cursor-dot-sizenumber (px)8Dot size
ringSizedata-aurora-cursor-ring-sizenumber (px)24Ring size
trailDelaydata-aurora-cursor-trail-delaynumber (ms)150Approximate time the ring takes to catch up with the dot. 0 makes it follow instantly.
interactiveSelectordata-aurora-cursor-interactive-selectorselectora, button, .cursor-pointerCSS selector for elements that shrink the dot and scale the ring on hover.
interactiveScaledata-aurora-cursor-interactive-scalenumber1.5Interactive ring scale
imageSelectordata-aurora-cursor-image-selectorselectorimg, .zoom-targetCSS selector for elements that grow the ring and tint it with the dot color on hover.
imageScaledata-aurora-cursor-image-scalenumber2.33Image ring scale
hideNativedata-aurora-cursor-hide-nativebooleanfalseHides the system cursor inside the zone (except over form fields). Off by default for accessibility.

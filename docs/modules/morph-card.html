Morph Card

A card that morphs between layouts on its own. Pass the states as JSON, or drive it from code with next() and goTo().

Open the standalone example

JavaScript API

var fx = Aurora.morphCard(document.querySelector('#card'), { states: [/* see the options table */] });
fx.api.next();         // go to the next state
fx.api.goTo(2);        // jump to a state
fx.destroy();

Options

Set them as data-aurora-morph-card-<option> attributes, as one JSON attribute (data-aurora-morph-card-options) or as an object in JavaScript.

OptionAttributeTypeDefaultDescription
statesdata-aurora-morph-card-statesjson[]JSON array of card states. The card shows them in order, morphing from one to the next.
loopdata-aurora-morph-card-loopbooleantrueLoop
autoplaydata-aurora-morph-card-autoplaybooleantrueOff shows the first state and waits for the API (next / goTo).
initialDelaydata-aurora-morph-card-initial-delaynumber (ms)0Initial delay
captionEffectdata-aurora-morph-card-caption-effectenumtypewriterPolaroid caption effect
typewriter letters
floatdata-aurora-morph-card-floatbooleantrueFloating motion
labelsdata-aurora-morph-card-labelsjson{}Overrides for the texts inside templates: likes, viewComments, posts, followers, following, follow, message, email.

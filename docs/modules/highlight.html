JavaScript API

var fx = Aurora.highlight(document.querySelector('h2'), { shape: 'circle', highlightColor: '#ff7a2f', trigger: 'load' });
fx.update({ shape: 'zigzag' }); // change options, including the shape
fx.replay();           // draw it again
fx.destroy();          // removes only the overlay it added

Options

Set them as data-aurora-highlight-<option> attributes, as one JSON attribute (data-aurora-highlight-options) or as an object in JavaScript.

OptionAttributeTypeDefaultDescription
shapedata-aurora-highlightenumunderlineWhich marker is drawn over the phrase.
underline double-underline scribble circle zigzag sawtooth strikethrough cross-out diagonal box brackets arc wave marker spark corner-ticks
triggerdata-aurora-highlight-triggerenumscroll"scroll" waits until the phrase is in sight.
scroll load
thresholddata-aurora-highlight-thresholdnumber0.2Capped at 5% internally, so a tall heading still draws.
targetdata-aurora-highlight-targetselectorCSS selector, relative to the element, of the node holding the text. Empty draws over the element itself.
highlightColordata-aurora-highlight-highlight-colorcolorEmpty keeps #e63946.
highlightWidthdata-aurora-highlight-highlight-widthstringKept even as the drawing is stretched to the phrase. Empty keeps 7px.
drawDurationdata-aurora-highlight-draw-durationstringEmpty keeps 1.1s.
highlightBleedXdata-aurora-highlight-highlight-bleed-xstringEmpty keeps 0.35em.
highlightBleedYdata-aurora-highlight-highlight-bleed-ystringEmpty keeps 0.3em.

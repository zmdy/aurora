Aurora for Elementor

The same modules, with a control for every option in the Advanced tab of your elements.

Download the plugin zip
  1. In WordPress, open Plugins, Add New, Upload Plugin and pick the zip. Activate it (Elementor must be active).
  2. Open any Heading, container, icon list or image in Elementor and find the Aurora sections in the Advanced tab.
  3. Add the Aurora Morph Card widget from the panel for the card module.
The plugin loads local files only: no CDN and no external requests. Modules you turn off in the Aurora settings page load nothing. The controls are generated from the module schemas, so they always match the standalone scripts.

Aurora in Webflow

No plugin and no build step. Add one snippet in Custom Code, then use Custom Attributes on any element.

  1. Custom code, head. In Site settings, Custom code, Head code add this. It hides animated text until Aurora runs, so there is no flash.
    <script>document.documentElement.classList.add("aurora-js");setTimeout(function(){document.documentElement.classList.add("aurora-ready")},4000)</script>
<style>
  .aurora-js:not(.aurora-ready) [data-aurora-text] { visibility: hidden; }
</style>
  2. Custom code, footer. In Footer code add the scripts of the modules you use.
    <script src="https://cdn.jsdelivr.net/gh/zmdy/aurora@v1.0.0/dist/aurora.core.min.js"
        integrity="sha384-/KWw2EHGQJKduEEYQl03x2DHIL61ZvlQuAffo/x4KSTbJrnW8aWNaLhW9Eh2IU8w"
        crossorigin="anonymous"></script>
<script src="https://cdn.jsdelivr.net/gh/zmdy/aurora@v1.0.0/dist/aurora.text.min.js"
        integrity="sha384-EWisSVVsUEICmGbc1Ql4ENBAn8reBWuj9dV04138FTJSEQDhz/ZzWsP1VEbnN3IM"
        crossorigin="anonymous"></script>
<script src="https://cdn.jsdelivr.net/gh/zmdy/aurora@v1.0.0/dist/aurora.children.min.js"
        integrity="sha384-tnhcBzaAMwmQVCVcg9Ut6pa8asGNyGc3FLzoKlyHI+42QUaR+BzwhpaGlVsnssGi"
        crossorigin="anonymous"></script>
<script>
  // Re-scan after Webflow finishes its own setup.
  window.Webflow = window.Webflow || [];
  window.Webflow.push(function () { Aurora.init(); });
</script>
  3. Custom attributes. Select an element in the Designer, open Settings, Custom attributes and add a name and a value.
    NameValueEffect
    data-aurora-textblur-revealAnimates the text of a Heading or Paragraph.
    data-aurora-text-splitwordsSplits by words instead of characters.
    data-aurora-childrenslideAnimates the direct children of a Div Block or Grid.
    data-aurora-children-stagger120Delay between children, in ms.
  4. Publish. Custom code only runs on the published site, not in the Designer canvas.

Tips

Collection lists. Put data-aurora-children on the Collection List Wrapper's list (the element that contains the items). Aurora animates the items, including ones that load later, because observe is on by default.
Rich text. Put data-aurora-text on the element that holds the text. For nested markup, add data-aurora-text-target with a CSS selector.
Designer Extension. A Designer app with a visual panel is a possible later step. Today the attributes are the interface.

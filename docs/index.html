Aurora is plain JavaScript. Pick the setup that fits your site.

The CDN links point to the tag v1.0.0 of the repository. You can also download the files from the dist/ folder of a release and host them yourself: they have no other dependencies.

Configuration

Define window.AuroraConfig before the scripts.

<script>
  window.AuroraConfig = {
    autoInit: true,  // scan the page for data-aurora-* on load
    observe: true,   // also watch the DOM for elements added later (CMS lists, routers)
    nonce: '',       // CSP nonce for the style tag Aurora injects
    debug: false
  };
</script>

Options, three ways

<!-- 1. Individual attributes -->
<h2 data-aurora-text="blur-reveal" data-aurora-text-duration="1200"></h2>

<!-- 2. One JSON attribute -->
<h2 data-aurora-text="blur-reveal" data-aurora-text-options='{"duration":1200,"split":"words"}'></h2>

<!-- 3. JavaScript -->
<script>
  Aurora.text(document.querySelector("h2"), { effect: "blur-reveal", duration: 1200 });
</script>

Bundlers

dist/aurora.esm.js is an ES module with every export.

import { createFullAurora } from './aurora.esm.js';

var aurora = createFullAurora();
aurora.init();
window.Aurora = aurora;

How It Works

From Idea to Animation in Minutes

01

Pick a Module

Choose the effect you want: text, children, gradient, cursor or morph card. Load only the ones you use.

02

Mark an Element

Add an attribute in your HTML or Webflow, or flip a switch in Elementor. Options are plain words and numbers.

03

Aurora Does the Rest

It finds the element, plays the animation when it scrolls into view and respects visitors who prefer less motion.

04

Tweak Until It Feels Right

Adjust timing, easing, triggers and hover behavior. The live playgrounds show every change as you make it.

<!-- That is all it takes: one element, a few attributes --> <h2 data-aurora-text="blur-reveal" data-aurora-text-split="words" data-aurora-text-duration="800" data-aurora-text-trigger="scroll" data-aurora-text-replay="true"> Your Heading Text Here </h2>

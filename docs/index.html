Animated web design, for any builder.

Aurora is an open-source toolkit of animation modules. Paste a script into plain HTML, drop it into Webflow, or install the Elementor plugin. Same modules, same attributes.

Get startedView on GitHub

Five modules

Use one or all of them. Each is a separate script that loads after the small core.

Morph Card

Three ways to use it

Standalone

Copy two script tags into any HTML page. No build step.

Webflow

Add the script in Custom Code, then use Custom Attributes in the Designer.

Elementor

A plugin with a control for every option, generated from the same schemas.

Built to stay light

No GSAP. Only Anime.js v4 (for text), native CSS and the Web Animations API. Everything respects prefers-reduced-motion.

Read the Docs

  • Text Animation

    Splits any text into characters, words, or lines and applies one of 70 animations (26 GSAP, 44 Anime.js), triggered on scroll or page load — plus an independent Hover Scatter interaction.

    01

  • Gradient

    Multi-stop linear, radial, or conic gradients with an animated mesh motion or a Follow Mouse spotlight — for backgrounds, text fill, icons, and Icon Box.

    02

  • Glassmorphism

    A translucent, blurred frosted-glass background resolved entirely in PHP into a single inline style — with a CSS fallback for browsers without backdrop-filter. Zero JavaScript.

    03

  • Cursor Follow

    Replaces the native cursor with a two-part custom cursor — a dot that tracks instantly and a ring that trails behind — with configurable hover states for interactive elements.

    04

  • Image Effects

    An entrance animation for the native Image widget — GSAP or Anime.js, scroll or load triggered — plus a pure-CSS hover effect, including a shine sweep.

    05

  • Animate Children Elements

    Applies a staggered entrance animation to each child of a Section, Column, Container, or Widget — one after another — with a configurable delay and 10 animation styles.

    06

Built for the way Elementor sites actually get made

About Aurora

Aurora bundles GSAP and Anime.js locally — no CDN dependency, no extra HTTP request per effect. On the real frontend, a widget only loads the ONE animation it actually uses alongside a small shared runtime, instead of shipping every effect to every page. Elementor Pro is not required.

Plugin Modules

Six Modules, One Plugin

Every module adds a section to Elementor's Advanced tab — no page builder lock-in.

✨
01 — Text Animation

70+ Text Effects

Split titles into chars, words, or lines and animate them with GSAP or Anime.js on scroll or page load. Add Hover Scatter for interactive depth.

🌈
02 — Gradient

Gradient & Spotlight

Multi-stop linear, radial, or conic gradients with animated mesh drift or a Follow Mouse spotlight. Applies as background or text fill.

🧊
03 — Glassmorphism

Frosted Glass Panels

Translucent blurred backgrounds resolved in PHP into a single inline style — with CSS fallback. Zero JavaScript. Zero overhead.

🖱️
04 — Cursor Follow

Custom Cursor Zones

A two-part cursor (dot + ring) with configurable trail delay and distinct hover states for links, buttons, and images inside each zone.

🖼️
05 — Image Effects

3D Tilt & Parallax

Gyroscope/mouse 3D perspective tilt, magnetic pull, and scroll parallax with configurable intensity and easing curves.

⚡
06 — Advanced Physics

Zero Dependencies

Vanilla JS core (12 KB gzipped). CDN fallbacks automatically injected only when needed — leaving your site fast and clean.

Swiss Architecture

Engineered for 100/100 PageSpeed

No framework bloat. No layout shifts. Pure GPU-accelerated motion.

01

Intersection Observer

Animations trigger only when scrolled into viewport with threshold awareness — saving main thread cycles.

02

DOM Splitting

Text is safely split into accessible spans preserving ARIA accessibility labels for screen readers.

03

GPU Compositing

All movement uses translate3d and opacity properties exclusively — avoiding browser repaint/reflow.

04

Auto Memory Cleanup

Observers and split instances automatically disconnect on unmount, keeping RAM footprint minimal.
